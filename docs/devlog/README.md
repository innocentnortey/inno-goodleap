# Dev log

One file per run in this folder, named `YYYY-MM-DD-<topic>-<run-id>.md` (dates in US Central time), one writer per
file. Each meaningful outcome gets a short entry with **Changed / Why / Checked / Remaining**. Ticket status,
stage gates and submission status stay in their owners (`PROJECT-CHECKLIST.md`, `SUBMISSION.md`); link them, don't
copy them. Contract: `icm-project` `references/dev-log.md`.

This index links the folder, not each entry; list the folder to find runs.
