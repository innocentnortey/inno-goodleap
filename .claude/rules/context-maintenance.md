# Keep the context true while working

1. **Reconcile in the same task.** When intent, a domain meaning, a boundary, a contract, a location, the
   workflow or a recurring lesson changes, update its owning record and the affected router rows, rule `paths:`
   and references in that same change.
2. **Link claims to their source or evidence.** Keep proposed, decided, planned, scaffolded, implemented,
   integrated and verified distinct. A scaffold proves locations exist, not that anything works.
3. **The entry is not a map.** Never put a code map, status, stage, decision list or history in `CLAUDE.md`. It
   changes only when the project's identity, a boundary or a route changes.
4. **One current status account per row** (area map, routes, ICM checklist, router): replace it in place, one
   clause per change; resolve a merge conflict by re-applying each change's own clause, never by keeping both
   sides. Narrative goes in the dev log.
5. **Durable implementation facts** that later work depends on (an export, a helper, a test double, a contract
   deviation) go into the owning area-map row or area route in the same change.
6. **Dev log:** one file per run in `docs/devlog/YYYY-MM-DD-<topic>-<run-id>.md`, one writer; add a short
   Changed / Why / Checked / Remaining entry at each meaningful outcome, not at the end. Delivery status goes to
   `PROJECT-CHECKLIST.md` and `SUBMISSION.md`, not the log.
7. **ICM checklist.** When a code design, scaffold, slice or test changes what a route can be checked against,
   update the affected row in `.claude/state/icm-progress.md` with status and an evidence link (replace, never
   append). It tracks context maturity, not product status.
8. **Reopen intake or design** when a change invalidates the brief audit, the PRD or the design.
9. **Keep the resume note current.** At a handoff, rewrite `.claude/state/resume.md`: phase, unresolved choices,
   next action. It links status owners; it is not a status ledger.
10. **Sources.** A new source goes into `docs/source/` with its rank in the register; confidential verbatim copies
    are added to `.gitignore` in the same change.
